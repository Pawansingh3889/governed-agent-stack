# Code of Conduct

## The short version

Be kind. Assume good faith. Critique code, not people.

## Expected

- Welcoming, patient language — especially with first-time contributors.
- Accepting constructive criticism gracefully, and giving it the same way.
- Focusing on what is best for people relying on this tool.

## Not accepted

- Personal attacks, harassment, or discriminatory language.
- Publishing others' private information without permission.
- Sustained disruption of discussions.

## Scope

Applies in issues, pull requests, commit messages, and anywhere someone is
representing the project.

## Enforcement

Report to the maintainer via GitHub. Reports are handled privately. Responses
range from a warning to a permanent ban, proportionate to the behaviour.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
